# Airbnb NYC 2019 Dashboard — Excel

## Project Overview
This project explores Airbnb listings in New York City using the Airbnb NYC 2019 dataset. The Excel workbook is designed to help analyze listing prices, room types, neighbourhood groups, reviews, and availability.

## Objectives
- Analyze Airbnb listings and pricing patterns.
- Compare average prices across neighbourhood groups.
- Explore listing distribution by room type.
- Examine review activity and availability.
- Present key findings using an Excel dashboard.

## Tools Used
- Microsoft Excel
- PivotTables and charts
- Data analysis and visualization

## Dataset
**Airbnb NYC 2019 Dataset**

The dataset contains information about Airbnb listings in New York City. Please include the original dataset source link when available.

## How to Use
1. Download the Excel workbook from this repository.
2. Open it in Microsoft Excel.
3. Navigate to the `DASHBOARD` sheet to explore the dashboard.
4. Review the supporting sheets for data and calculations.
