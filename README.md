# Airbnb NYC 2019 Dashboard — Excel

## Project Overview
This project analyzes Airbnb listings in New York City using Microsoft Excel. It explores listing prices, room types, neighbourhood groups, reviews, and availability through data analysis and dashboard visualization.

## Tools Used
- Microsoft Excel
- Charts and data visualization
- Dashboard design

## Project Objectives
- Analyze Airbnb listing prices.
- Compare listings across neighbourhood groups.
- Explore room types and listing distribution.
- Understand review patterns and availability.
- Present data through a visual dashboard.

## Project File
`AB_NYC_2019 dashboard.csv (1).xlsx`

## Key Learnings
- Data analysis using Excel
- Dashboard creation and visualization
- Presenting information clearly
